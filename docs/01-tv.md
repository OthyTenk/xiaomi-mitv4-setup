# 1. The TV: specs and research

**English** · [Монгол](01-tv.mn.md)

## Specs

Read over ADB on 2026-10-31.

| | |
|---|---|
| Model | `MiTV4-ANSM0`, codename `xmen`, platform 666 (`txl_xmen_t46k`). The Amlogic variants of the Mi TV 4 series share this name |
| Panel | CSOT 55", 3840×2160. The UI runs at 1920×1080, density 320 (≈960×540dp) |
| Chip | Amlogic T962 (TXL), 4× Cortex-A53. The kernel is 64-bit, but apps are **32-bit only** (armeabi-v7a) |
| GPU | OpenGL ES 2.0 |
| RAM | 2GB (1.6GB available to the system) |
| eMMC | 8GB: system 1GB (**86MB free**), data 5.8GB |
| Android | 6.0.1 (API 23), security patch 2017-04-01, kernel 3.14.29 |
| Firmware | MiTV OS 1.3.128, build 22.4.15.3235 (2022-04-15), `user/release-keys`. No root, SELinux enforcing |
| Tuner | si2151 (Chinese DTMB) |
| DRM | Widevine disabled (`media.amplayer.widevineenable=false`) |
| Open ports | 6087, 6088, 6091, 6093, 6095 (Mi TV Assistant), 9093, 9095, 49152 (DLNA). 5555 while ADB is on |
| Root CAs | 158 of them. **ISRG Root X1 (Let's Encrypt), Sectigo R46 and GTS Root R1 are missing** |

Full getprop: `info/getprop-2026-10-31.txt` (not in the repo, because it contains serial numbers and MAC addresses).
Package list before any change: [`info/packages-before-2026-10-31.txt`](../info/packages-before-2026-10-31.txt).

The missing roots in the last row matter. Most newer sites chain to them, so HTTPS fails unless an
app bundles its own root certificate. This broke Breezy's NAMEM source and YoWindow
([docs/06](06-weather.md)).

### Can the root CAs be updated? No (checked 2026-10-31)

| Approach | Why it doesn't work |
|---|---|
| Edit the system CA store (`/system/etc/security/cacerts`) | Needs root |
| Add a user CA (on Android 6 every app trusts user CAs) | Xiaomi removed the **`com.android.keychain`** service, which stores user CAs, and AOSP Settings' `CredentialStorage` from this firmware. CertInstaller is still there, but it has nothing to hand its last step to |
| Device owner app + `DevicePolicyManager.installCaCert()` | This also goes through KeyChain. Also, a device owner can't be set over ADB while accounts are registered (Xiaomi, Aerial). Not tried, because system_server may crash without KeyChain |
| Set a screen PIN and use CertInstaller | There's no menu to set a PIN, and KeyChain would still be missing |

So every app that talks to a site with a newer root has to bundle that root itself. The Weather app
bundles ISRG X1/X2 this way. Other people's apps (such as Breezy's NAMEM source) can't be fixed. Use
the Mi Box S for apps that need modern TLS.

## Can it become Android TV with Google Play? No

- **There's no matching firmware.** Xiaomi doesn't release Google-certified Android TV firmware for
  the TVs it sells in China. The Global and India models use different boards and chips.
- **There's no way to install another firmware.** The firmware is signed by Xiaomi
  (`release-keys`), part of the secure boot key is in efuse, and there's no root. Forcing a flash
  (with a USB burning tool) is very likely to brick the TV.
- **There's no room for Google's apps.** The system partition has only 86MB free, so even with root,
  Google Play Services couldn't be installed as a system app.
- **The platform is outdated.** With Android 6, 32-bit apps and Widevine disabled, Netflix and other
  HD streaming services don't work. Many new apps need Android 7–8+.
- **Installing the Play Store as a normal app is unstable.** Google blocks the device as
  "uncertified", so it isn't recommended.

## Recommendation: use the Mi Box S for Android TV

The Mi Box S connected over HDMI has Android TV 9, Google Play and official Netflix support.

- If the TV settings have "Power-on input / 开机信号源", set it to HDMI. The TV then goes straight
  to the Mi Box when it turns on.
- Turn on HDMI-CEC ("HDMI 控制") to turn the TV on and off and change the volume with the Mi Box
  remote.
- In Aerial, the HDMI input can be pinned under the name "Mi Box" ([docs/03](03-aerial.md)).

## First findings without ADB

- `http://<TV-IP>:6095/request?action=isalive`: device name, platform 666, build 3235. This is the
  TV's "Phone can control TV" (Mi TV Assistant) service.
- `http://<TV-IP>:49152/description.xml`: UPnP/DLNA (Xiaomi hyperDLNA).
- mDNS: the TV announces AirPlay (`_airplay`). The Mi Box S announces `_googlecast` and
  `_androidtvremote2`.
